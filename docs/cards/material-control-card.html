🔗 Material Control Card ​

🌟 Overview ​

The material-control-card is a versatile card designed to trigger actions, navigate between views, or control entities with a clean, touch-first button interface inspired by Google and Material 3 Expressive. In the Pro version, it supports a smooth horizontal kinetic Carousel / Slider to group multiple control items together with inertia, snap, and touch gestures.

☀️ Light Mode

🌙 Dark Mode

🎨 Features ​

  • 📱 Google & M3-inspired layout: Minimalist, tactile rounded button interface.
  • 🔗 Entity Binding: Link the button to an entity to reflect its current state and friendly name.
  • 🔄 Adaptive Dual-State Icons: Configurable icons for active and inactive states.
  • 👆 Interactive Touch Actions: Built-in support for tap and hold actions.
  • 🌓 Dynamic Theme Adaptation: Automatic adaptation to Home Assistant light and dark themes.

🚀 Usage Examples ​

1. Navigation Button ​

yaml
type: custom:material-control-card
name: Go to Lights
icon: mdi:lightbulb-group
tap_action:
  action: navigate
  navigation_path: /lovelace/lights

2. Entity Toggle ​

yaml
type: custom:material-control-card
name: Desk Lamp
use_card_entity: true
entity: switch.desk_lamp
tap_action:
  action: toggle

3. Dual Icons ​

yaml
type: custom:material-control-card
name: Garage Door
use_card_entity: true
entity: binary_sensor.garage_door
use_default_icon: false
dual_icon: true
icon_on: mdi:garage-open
icon_off: mdi:garage

🚀 Pro & Ultimate Features ​

The Paid (PRO/ULTIMATE) version of material-control-card has been completely rebuilt as a high-performance native LitElement Web Component adhering to Material 3 Expressive:

  • ⚡ Zero External Dependencies: Eliminates custom:button-card, custom:swipe-card, and js-yaml. 100% native LitElement component with instant rendering and direct Home Assistant WebSocket reactivity.
  • 🎚️ Touch-First Kinetic Carousel & Slider: Group multiple control buttons (controls) in a smooth horizontal scrollable carousel with hardware-accelerated transforms, low-pass velocity filtering, rubber-band elasticity, magnetic snapping (148px step), and wheel assist.
  • 🛡️ Zero Background Spacing: Individual 140x140px ha-card buttons with transparent container spacing—no background rectangle or outlines behind or between cards.
  • 🛡️ Accidental Click Protection: Kinetic touch gestures and swipes automatically prevent accidental click or tap triggers while dragging.
  • 🔗 Direct Entity Association: Directly assign an entity without needing intermediary boolean toggles (use_card_entity).
  • 🎨 Smart State & Dual Icons: Automatically uses the entity's icon or enables state-reactive dual icons (icon_on / icon_off), custom colors, and custom backgrounds.
  • 👆 Unified Action Control Hub: Full support for Tap, Hold, and Double-Tap gestures using the standard action engine (handleAction, actionHandler), safely isolated from drag/scroll gestures.
  • 🚨 Contextual Alarm Dialog & Cameras (Ultimate): Seamless integration with alarm_control_panel entities, featuring security PIN keypad, live camera feeds, and sensors overlay.
  • 🌊 Tactile Touch & Haptic Feedback: Material 3 physical press animation (scale(0.96)), dynamic ripple effect, and subtle haptic vibration pulses (light) on touch devices.
  • 🛠️ Modern ha-form UI Editor: Visual configuration interface with elevated 60px expansion panels, drag-and-drop reordering, pill-shaped '+ Aggiungi Controllo' button, item-level action panels, and a dedicated one-click migration banner for legacy single-entity configs.

🚀 Usage Examples ​

1. Multi-Item Controls Carousel (Slider) ​

Create a smooth horizontal scrollable collection of control buttons:

yaml
type: custom:material-control-card
controls:
  - name: Salotto
    entity: light.salotto
    tap_action:
      action: toggle
  - name: Cucina
    entity: light.cucina
    tap_action:
      action: toggle
  - name: TV
    entity: media_player.living_room_tv
    icon: mdi:television
    tap_action:
      action: toggle
  - name: Clima
    entity: climate.termostato
    icon: mdi:thermostat
    tap_action:
      action: more-info

2. Contextual Alarm Control with Camera Integration (Ultimate) ​

Link a control item to an alarm entity to automatically trigger the security dialog with camera streams:

yaml
type: custom:material-control-card
controls:
  - name: Allarme Casa
    entity: alarm_control_panel.home_alarm
    icon: mdi:shield-home
    tap_action:
      action: more-info
    settings:
      show_keypad: true
      show_camera_on_panel: true
      cameras:
        - camera_entity_stream: camera.front_yard
          camera_title: Giardino Frontale

3. Single Navigation Button ​

yaml
type: custom:material-control-card
controls:
  - name: Go to Lights
    icon: mdi:lightbulb-group
    tap_action:
      action: navigate
      navigation_path: /lovelace/lights

4. Entity Toggle with Direct Binding ​

5. Dual State Icons with Long-Press Action ​

    hold_action:
      action: toggle

🔄 Migration Guide (from Legacy / Free) ​

If you are upgrading from the Free version or a legacy single-entity configuration:

  1. Automatic One-Click Migration: Open the card in the visual Lovelace editor. A banner will automatically detect your existing configuration and provide a "Migra alla nuova versione" button to convert it into the new format instantly.
  2. Manual YAML Update: Simply wrap your existing card parameters inside the controls array:
yaml
# ❌ Before (Legacy)
type: custom:material-control-card
entity: light.living_room
name: Salotto
tap_action:
  action: toggle

# ✅ After (Modern Multi-Control Carousel)
type: custom:material-control-card
controls:
  - entity: light.living_room
    name: Salotto
    tap_action:
      action: toggle
