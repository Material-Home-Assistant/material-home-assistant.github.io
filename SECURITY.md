# Security Policy

## Supported Versions

We are committed to providing security updates for the latest major version of Material Home Assistant. Please ensure you are running the most up-to-date version to receive security patches.

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| 1.x.x   | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability within Material Home Assistant, please report it responsibly.

**DO NOT open a public issue or disclose it publicly.**

Instead, please send an email to `security@materialhomeassistant.com` (or your designated security email address). We will do our best to respond to your report within 48 hours.

When reporting a vulnerability, please include the following details:

- A clear description of the vulnerability.
- The version of Material Home Assistant affected.
- Steps to reproduce the vulnerability.
- Any proof-of-concept code or screenshots.

We will work with you to address the vulnerability and will publicly acknowledge your contribution once the vulnerability has been patched.

Thank you for helping us keep Material Home Assistant secure.
